# 🛠️ Fullstack Practice

프론트엔드와 백엔드 통합 연습을 위한 레포지토리입니다.

---

## 📌 목적

각자 브랜치를 생성하여 프론트엔드 ↔ 백엔드 연동을 자유롭게 실습합니다.

---

## 🌿 브랜치 규칙

본인 이름 또는 닉네임으로 브랜치를 생성해 주세요.

```
git checkout -b fullstack/이름

```

## ✅ 커밋 컨벤션

| 태그 | 설명 |
|------|------|
| `[feat]` | 새로운 기능 추가 |
| `[fix]` | 버그 수정 |
| `[refactor]` | 코드 리팩토링 |
| `[chore]` | 설정, 패키지 등 기타 작업 |

예시: `[feat] 로그인 API 연동 완료`

---

## 🚫 주의사항

- `main` 브랜치에 직접 push하지 않습니다.
- 다른 사람의 브랜치는 건드리지 않습니다.
